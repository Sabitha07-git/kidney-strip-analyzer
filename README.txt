NephroScan — Kidney Strip Analyzer
===================================

Setup:
  pip install -r requirements.txt

Run:
  python app.py

Then open:  http://127.0.0.1:8000

Python 3.9+ required.

Changes in this build
---------------------
- Insights moved inside the Learn More tab (not a separate top-level tab).
- Learn More jump nav now shows: About Us | Future | Insights
- Clicking Insights scrolls to the Insights section below Future.
- Insights contains two styled cards: Thesis/Report and Flowchart.
